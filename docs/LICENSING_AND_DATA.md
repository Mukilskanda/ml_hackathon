This is an inventory of the material supplied and prepared here, not a grant of rights to other parties' data.

- Neither supplied ZIP contains a README, LICENSE, COPYRIGHT or terms file. The five organizer PDFs specify public source submission and a separate report, but no standalone dataset redistribution license was found.
- Do not put raw `.track`, `.nodes`, `.arcs` or `.route` files, private deployment ZIPs, cache arrays or bulk per-point results in the public repository by default.
- Detailed coordinates, point-label arrays and interactive maps remain in the private working project/backup. Public source includes the code needed to generate them from legitimately supplied inputs.

- `THIRD_PARTY_NOTICES.md` records the installed dependency metadata and license identifiers/text references where available. Missing/ambiguous metadata is labeled, not guessed. Upstream dependency terms remain applicable.
- No team source-code license was specified. No blanket MIT/Apache license or license to the supplied dataset has been invented. Add a team-approved source license only if appropriate; it does not license the dataset.
- The local development Git history contains detailed derived records. The curated publication snapshot starts without that private history. Preserve the local development repository privately for reproducibility and investigation.
